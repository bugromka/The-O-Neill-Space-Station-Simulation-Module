# ММОСО'Н

**Модуль моделирования орбитальной станции О'Нилла**

Расчётная модель обитаемой орбитальной станции цилиндрического типа
для точки L1 системы Земля — Солнце.

Проект «Уютные регионы», Курское региональное отделение МХ «КРЯК».
Направление «Урбанистика и картография» → «Космическая систематика».

---

## Основные параметры

| Величина | Значение |
|---|---|
| Радиус цилиндра | 5 000 м |
| Длина цилиндрической части | 40 км (полная 49 км) |
| Число цилиндров | 2, встречного вращения |
| Угловая скорость | 0,04429 рад/с — 0,423 об/мин |
| Тяжесть на ободе | 1,0 g |
| Материал оболочки | сталь 18Ni(300), пояс 850 мм |
| Полная площадь | 1 550,1 км² |
| Масса станции | 46,70 млрд т |
| Население | 1 000 000 человек |
| Электрическая мощность | 721,4 ГВт |
| Место размещения | точка L1 Земля — Солнце |

Освещение — только реакторное, через осевые светотепловые балки.
Зеркал и солнечного паруса у станции нет.

## Проверка расчётов

```bash
cd src
python3 verify_all.py      # сквозная проверка величин
python3 crosscheck.py      # сверка чисел «текст ↔ таблицы»
python3 check_overlap.py   # контроль наложений в документе
```

`verify_all.py` пересчитывает величины документа независимо и сверяет
с напечатанными. Текущее состояние — **228 из 228**.

## Сборка документа

```bash
cd src
python3 build_docx_v7.py
```

Требуется `python-docx`, `matplotlib`.
